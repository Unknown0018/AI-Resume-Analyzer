#AI Resume Analyzer

An AI-powered web application that analyzes resumes, evaluates ATS compatibility, extracts key skills, and provides personalized improvement suggestions. The application also supports secure user authentication and displays relevant job opportunities.

Features
AI-powered resume analysis
ATS score evaluation
Resume upload (PDF)
Skill extraction and recommendations
Secure login and registration
Email verification and password reset
Job recommendations
Responsive user interface
Tech Stack

#Frontend

Spring Boot

Google Gemini API

#Project Architecture
Frontend built with React.js
RESTful APIs developed using Spring Boot
MySQL for user and application data
AI integration for resume analysis
Secure authentication using JWT
Installation
Clone Repository
git clone https://github.com/Unknown0018/ai-resume-analyzer.git
Install Backend
mvn clean install
Configure application.properties

Add your:

MySQL credentials
Gemini API Key
Brevo API Key
Adzuna API Key
JWT Secret Key
Run Application
mvn spring-boot:run

Open

http://localhost:8080
